# Phase 11 - Testing And Quality Gate

## Objective

Dam bao logic data, cham diem, exam va animation on dinh.

## Backend Test Cases

1. Import dung 600 cau.
2. Cau hoi khong expose `isCorrect`.
3. Submit answer dung.
4. Submit answer sai.
5. Reject answer khong thuoc question.
6. Exam pass khi du diem va khong sai diem liet.
7. Exam fail khi sai cau diem liet.
8. Animation API tra dung question id.

## Frontend Test Cases

1. Render danh sach chuong.
2. Render cau hoi.
3. Chon dap an.
4. Submit va hien loi giai.
5. Play animation.
6. Replay animation.
7. Timer exam.
8. Result page.

## Success Criteria

- Backend tests pass.
- Frontend build pass.
- Manual smoke test pass tren Chrome va mobile viewport.
