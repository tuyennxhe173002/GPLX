# Phase 12 - Deployment

## Objective

Deploy website bang Docker Compose voi frontend, backend va PostgreSQL.

## Tasks

1. Tao Dockerfile cho backend.
2. Tao Dockerfile hoac static build flow cho frontend.
3. Tao Nginx config serve React.
4. Proxy `/api` ve backend.
5. Cau hinh PostgreSQL volume.
6. Cau hinh production env.
7. Cau hinh HTTPS.
8. Backup database.
9. Smoke test production.

## Success Criteria

- Website chay qua domain.
- Anh cau hoi load duoc.
- API load duoc.
- Animation load duoc.
- Restart container khong mat data.
