# Phase 9 - Exam Frontend

## Objective

Tao UI thi thu co timer, navigator va trang ket qua.

## Pages

```text
/exam
/exam/:sessionId
/exam/:sessionId/result
```

## Tasks

1. Tao trang chon hang bang.
2. Goi start exam API.
3. Tao exam timer tu `expiresAt` cua server; frontend chi display countdown.
4. Tao cau hoi hien tai.
5. Tao question navigator.
6. Luu selected answers qua exam answer API ma khong hien dung/sai.
7. Tu dong nop bai khi het gio hoac reload session tu backend neu can.
8. Tao result page.
9. Tao review wrong answers va explanation sau khi exam ket thuc.

## Success Criteria

- User lam duoc de thi tu dau den cuoi.
- Het gio nop bai theo timer server truth.
- Ket qua hien dung pass/fail.
- Frontend khong lam lo dap an truoc submit.
